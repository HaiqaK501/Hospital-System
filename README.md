# Hospital_Management_System
hospital mng system

## How to Compile & Run

### Prerequisites
- Visual Studio 2022 (or C++17 compiler)
- SFML 2.6+ (https://www.sfml-dev.org/)

### Visual Studio Setup
1. Open `Hospital_Management_System.sln`
2. Project → Properties → C/C++ → Additional Include Directories → Add SFML `include` path
3. Linker → General → Additional Library Directories → Add SFML `lib` path  
4. Linker → Input → Additional Dependencies → Add:
   sfml-graphics.lib
   sfml-window.lib
   sfml-system.lib
